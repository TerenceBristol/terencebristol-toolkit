# Start here: set up your first Claude Code folder

Give Claude Code one PDF and it interviews you, then writes the CLAUDE.md file that tells Claude how you work. Nothing is written until you say "OK, write it".

**Works in:** Claude Code (the Code tab of the Claude desktop app, or the terminal). It needs to write a file in your folder, so it won't work in the Claude app's chat.

## Get it

Open [START-HERE.pdf](START-HERE.pdf) and click "Download raw file" (the arrow icon at the top right).

## How to use it

1. Make an empty folder for one role, for example your main job.
2. Put START-HERE.pdf in it.
3. Open that folder in the Code tab (the `</>` icon at the top) of the Claude desktop app.
4. Type: `Read START-HERE.pdf and set me up.`
5. Answer one short question at a time, out loud if you can. Claude shows you a draft first.

## What it does

- Claude tells you in three short lines what the folder is for, then interviews you: your role, the people you work with, and how you like your work written.
- It drafts a short CLAUDE.md for this folder and asks whether any part belongs in your global CLAUDE.md, so it applies to all your work. If you already have a global file, it adds to it and never deletes what you didn't ask to change.
- It follows six best practices for a good CLAUDE.md: only what Claude can't learn by itself, a short reason on each preference, short and plain, global and folder kept apart, no passwords or keys, and a read-back before saving.
- When the file is saved, it suggests a quick test in a new conversation and your next step: turning a result you like into a skill.
