# Set up Claude Code as your video editor

Give Claude Code one page and it interviews you, checks your computer and your editing app, then builds your own video editor with you, one step at a time. You record, Claude does the heavy lifting, and you stay in charge of every decision.

**Works in:** Claude Code (tested with clean Claude Code runs in the terminal, with simulated first-time users on Mac and Windows; the Code tab of the Claude desktop app is not yet tested). It needs to look at your computer and work with files, so it won't work in the Claude app's chat. Claude Code needs a paid Claude plan or API credits; this page is free.

## Get it

Open the page: [Set up Claude Code as your video editor](https://terencebristol.github.io/terencebristol-toolkit/prompts/video-editor-setup/VIDEO-EDITOR-SETUP.html).

## How to use it

1. Make a folder for your video work, or open Claude Code in the one you have.
2. On the page, click "Copy prompt for Claude" and paste it into Claude Code. Or click "Download this page", move the file into that folder and type: `Read VIDEO-EDITOR-SETUP.html and set me up.`
3. Answer one short question at a time. Claude asks what editing app you use (or if you use none) before it researches anything.
4. Claude Code asks before it runs a command or changes a file: read it, and say yes when it makes sense.

## What it does

- **Step 1, a short intake:** your editing app, the videos you make, and what to hand over first (the rough cut, the graphics, or both).
- **Step 2, check and research:** Claude looks at your computer and your editing app itself, researches how it can work with that app today, and tells you the trade-offs and the one-time setup before it installs anything.
- **Step 3, the deeper interview, then the build:** only what the first result needs, each question with Claude's suggested answer, then the first rough cut or graphic.
- It includes advice for your Claude on what usually works (a transcript with a timestamp for every word, a timeline you can still polish, a still before each animation, checking its own work), not rules: your style stays yours.
