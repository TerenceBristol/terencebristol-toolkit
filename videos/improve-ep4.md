# I Kept Correcting Claude. Now It Improves Itself

Video: https://youtu.be/UCdYea40AvQ

Everything from this video, free.

## Items

- [/improve](../skills/improve/): reads your past Claude Code conversations, finds the corrections you keep repeating and outdated guidelines to cut, and suggests changes to your CLAUDE.md and skills. You accept or skip each change on one findings page. Use it as is, or as inspiration to build your own.

## Prompts from the video

To install /improve, give Claude the link and ask it to install it for you:

```
install this skill: github.com/TerenceBristol/terencebristol-toolkit
```

Add "/improve" at the end if Claude asks which skill you mean, or paste the skill's own link: https://github.com/TerenceBristol/terencebristol-toolkit/tree/main/skills/improve

Got /improve from my April video? Delete your old `~/.claude/commands/improve.md` first, or it hides the new one.

The first time you run it, open Claude Code in a folder you already use and pick the option that reads all of your past conversations there, so it has a lot to learn from. After that, a good time to run it is after a session where you had to correct Claude a lot.
